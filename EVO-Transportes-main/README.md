# EVO Logística - Sistema de Gestão de Transportes

Sistema incremental para controle de fluxo de carga e descarga em tempo real.

## 🚀 Funcionalidades
- **Portal do Motorista**: Cadastro de entrada com foto e geolocalização.
- **Controle de Portaria**: Interface para liberação de entrada.
- **Painel de Gerenciamento**: Gestão de usuários, status de descarga e relatórios WhatsApp.
- **Visualização Operacional**: Dashboard em tempo real para monitoramento do pátio.
- **Chat Integrado**: Comunicação em canais globais e setoriais.

## 🛠️ Tecnologias
- HTML5 / Tailwind CSS
- JavaScript (ES6 Modules)
- Firebase Realtime Database
- FontAwesome Icons

## 📋 Como usar
1. Realize o login (usuário padrão: `EricLM` / senha no `bd.js`).
2. Motoristas registram a chegada.
3. Portaria libera o acesso.
4. Admins gerenciam o fluxo de descarga no painel de gerenciamento.
5. Todos os setores podem acompanhar o status no painel de visualização.
